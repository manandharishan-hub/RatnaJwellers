\# Ratna Project Requirements



\## Project Overview

Ratna is a Next.js e-commerce web application that allows users to browse products, add products to cart, complete checkout, and manage orders. The system also includes an admin side for product and order management.



\## Technology Stack

\- Next.js

\- TypeScript

\- MongoDB

\- Tailwind CSS

\- eSewa

\- Firebase



\## User Features

\- User registration

\- User login

\- Product listing page

\- Product detail page

\- Shopping cart

\- Checkout process

\- Order placement

\- Order history



\## Admin Features

\- Admin dashboard

\- Add product

\- Edit product

\- Delete product

\- View orders

\- Manage order status



\## Database Requirements

\- Store users in MongoDB

\- Store products in MongoDB

\- Store cart/order data in MongoDB

\- Use proper database models



\## Payment Requirements

\- eSewa payment integration

\- eSewa checkout initiation

\- Payment success and failure pages



\## Image Requirements

\- Firebase image upload or image storage support

\- Product images displayed on product pages



\## Testing Requirements

\- Check build errors

\- Check API routes

\- Check user flow

\- Check admin flow
